# The-Skywhale-Chronicles-Bullie-Brigade-ajax-project
Based upon the book, The Skywhale Chronicles: The Bullie Brigade - Book 1 Above the ruins
By C. Wright 
[https://www.amazon.com/Bullie-Brigade-Above-Ruins-Chronicles/](https://a.co/d/0eOyuwtj)

For this project, I used a mix of examples, my own ideas, and some AI help. I started by looking at the W3Schools jQuery AJAX example to figure out how `$.getJSON()` works and how to loop through the data. That gave me a basic understanding of how to actually pull in and display a JSON file. After that, I built my own version and customized it to match my "SkyWhakke Chronicles: Bullie Brigade" theme. Instead of just dumping the data on the page, I turned it into a “Skywhale crew dossier” so it felt more like something from my world. I made my own JSON file with character info and focused on making it look intentional and styled.

For the plugin, I figured out how to use `$.fn` by experimenting and looking at examples, then made a simple effect that adds styling and hover animation to each card. It helped me understand how plugins can be reused across elements.

AI helped mostly when I got stuck, especially with debugging stuff like why the JSON wasn’t loading or why my plugin wasn’t working. I didn’t just copy though—I tested things, changed them, and made sure I understood what was happening.

So overall, I used examples to learn the basics, built my own creative version, and used AI as support when I needed help figuring things out.
